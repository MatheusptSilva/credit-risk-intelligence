
# Data Source

This project uses the **Home Credit Default Risk** dataset, made available through a Kaggle competition.

The original data files are not stored in this repository. To reproduce the analysis, download the source data and upload it to your Databricks workspace.

## Source

- Dataset: [Home Credit Default Risk](https://www.kaggle.com/competitions/home-credit-default-risk/data)
- Provider: Home Credit Group
- Purpose: Educational portfolio project only

## Files Used

- `application_train.csv`
- `previous_application.csv`
- `installments_payments.csv`

## Data Privacy and Limitations

The dataset contains anonymized historical customer information. This project does not use personally identifiable information and does not represent the Brazilian credit market.

All insights and recommendations are for educational and portfolio purposes only.
