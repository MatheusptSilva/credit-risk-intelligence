# Fonte de Dados

Este projeto utiliza o dataset **Home Credit Default Risk**, disponibilizado por meio de uma competição no Kaggle.

Os arquivos de dados originais não estão armazenados neste repositório. Para reproduzir a análise, baixe os dados na fonte e envie para o seu workspace do Databricks.

## Origem

- Dataset: [Home Credit Default Risk](https://www.kaggle.com/competitions/home-credit-default-risk/data)
- Fornecedor: Home Credit Group
- Finalidade: projeto de portfólio para fins educacionais

## Arquivos Utilizados

- `application_train.csv`
- `previous_application.csv`
- `installments_payments.csv`

## Privacidade e Limitações dos Dados

O dataset contém informações históricas de clientes de forma anonimizada. Este projeto não utiliza informações pessoais identificáveis e não representa o mercado de crédito brasileiro.

Todos os insights e recomendações têm finalidade exclusivamente educacional e de portfólio.
